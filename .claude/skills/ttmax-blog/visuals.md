# Обложка и схемы статьи

## Обложка (обязательна)
Обложка — **фон под заголовок**: логотип, H1, автора и дату рисует `ArticleCover.tsx` поверх, с затемнением слева. Поэтому левая половина кадра должна быть пустой, а сюжет — справа.

**Основной путь — Canva-коннектор** (так просит владелец):
1. `create-design`. Промпт: тёмный фон, сюжет справа, левая половина свободна, **без текста и цифр**. Сюжет показывает механизм статьи, а не «что-то про теннис».
2. `export-design` → PNG шириной 1400 → скачать.
3. Через sharp: расширить полотно влево `extend({ left: 600, extendWith: "copy" })` (≈1,9:1, близко к OG 1,91:1), затем сжать `png({ palette: true, quality: 90 })` → `public/blog/<slug>-cover.png`.
4. `coverSrc: "/blog/<slug>-cover.png"`. Растровая обложка сама уходит в og:image.

`generate-image` в Canva отдаёт только миниатюру — для обложки не годится. Если `create-design` вернул `quota_cooldown`, используйте запасной путь.

**Запасной путь — SVG-генератор:** добавить сюжет в `scripts/gen-blog-covers.mjs` (правила и безопасная зона: `scripts/gen-blog-covers.md`; зона x 780–1330, y 200–850 в viewBox 1400×1050), `node scripts/gen-blog-covers.mjs` → `public/blog/<slug>-cover.svg`. Для SVG-обложки обязательно `node scripts/gen-og-covers.mjs`: PNG 1200×630 в `public/blog/og/` (мессенджеры не показывают SVG). Закоммитить PNG — на Vercel нет шрифтов для их генерации.

Проверять на собранной странице, на `/ru/` (заголовки длиннее), а не на самом файле.

## Схемы с данными
Любые числа на картинке — только из генератора, не руками: нарисованная вручную цифра разойдётся с каталогом.
- Новый скрипт `scripts/gen-<тема>-diagram.mjs` по образцу `scripts/gen-care-diagram.mjs`: палитра и шрифты копируются из него, вывод — `public/blog/<имя>-{ua,ru}.svg`, подписи переведены.
- Данные брать из каталога (`src/data/catalog/*.ts`), где это возможно; иначе — константы с комментарием-источником в шапке скрипта.
- В шапке скрипта указать: для какой статьи, источники, команду запуска. Если числа меняются — синхронно править текст статьи.
- В секции: `image: { src: { ua: "/blog/<имя>-ua.svg", ru: "/blog/<имя>-ru.svg" }, alt: {…}, caption?: {…} }`.
- Проверка: открыть страницу в preview на мобильной ширине — подписи читаются, ничего не обрезано.
