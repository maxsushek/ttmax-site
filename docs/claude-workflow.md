# Как работать с Claude Code над TT Max экономно

Памятка для владельца. Claude её не загружает — правила для Claude лежат в `CLAUDE.md`.

## Что расходует лимит
Каждое сообщение отправляет модели **всю историю сессии**: длинный разговор становится дороже с каждым шагом. Больше всего расходуют:
1. **Длинные сессии с разными темами.** Статья + отзывы + Telegram + аналитика в одном чате — каждый новый шаг тащит всё предыдущее.
2. **Чтение больших файлов и объёмные ответы сервисов** (это ограничено в `CLAUDE.md`).
3. **Модель Opus и высокий уровень рассуждений** там, где хватило бы Sonnet.

## Правила
- **Одна задача — одна сессия.** Закончили задачу — `/clear` (или новая сессия). Контекст проекта вернётся из `CLAUDE.md` сам.
- **Длинную задачу** заканчивайте фразой «запиши в память, что сделано и что осталось» — следующая сессия начнёт не с нуля.
- **Пишите задачу целиком в первом сообщении:** что сделать, где (если знаете), критерий готовности, деплоить или нет. Уточнения по ходу — самые дорогие сообщения.

## Какая модель
| Задача | Модель | Рассуждения |
|---|---|---|
| Тексты, статьи, правки контента, переводы UA↔RU | Sonnet | средние |
| Мелкие правки кода, вёрстка, поправить цену/ссылку | Sonnet | низкие |
| Новая функция, интеграция, миграция БД | Opus | средние |
| Сложный баг, кэш/ISR, производительность, безопасность | Opus | высокие |

Модель и уровень рассуждений выбираются в приложении перед задачей.

## Шаблон запроса на статью
> Статья блога: «<тема>». Целевые запросы: UA «…», RU «…». Источники: <ссылки, если есть>. Деплоить после проверки: да/нет.

Claude подхватит skill `ttmax-blog` автоматически. Обложка делается через Canva.

## Деплой
- Каждый push в `main` — сборка сайта (квоты Vercel и Supabase). Просите группировать изменения: «закоммить, задеплою вместе с …».
- Изменения только в документации, `.claude/`, `scripts/` или `supabase/` сборку не запускают.

## Коннекторы
Для TT Max нужны Supabase, PostHog и Canva. Vercel, Figma, Google Drive и Upwork выключены, чтобы их сотни инструментов не занимали контекст. Включить: «+» → Connectors.
