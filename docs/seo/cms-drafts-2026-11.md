# CMS-чернетки: /nakladki, /odyag, /nakladki/dignics, /nakladki/tenergy

Куди вставляти: /admin → «Контент» → тип сутності → slug → мова (uk / ru) → «Завантажити» → правка → «Зберегти».
Збереження в адмінці само скидає кеш, тому текст з'явиться на сайті без деплою.

| Сторінка | Тип сутності | slug |
|---|---|---|
| /ua/nakladki, /ru/nakladki | Категорія (`category`) | `nakladki` |
| /ua/odyag, /ru/odyag | Категорія (`category`) | `odyag` |
| /ua/nakladki/dignics, /ru/nakladki/dignics | Серія (`series`) | `dignics` |
| /ua/nakladki/tenergy, /ru/nakladki/tenergy | Серія (`series`) | `tenergy` |

Поля в адмінці (`src/components/admin/ContentEditor.tsx`): **Meta title** (~60), **Meta description** (~155), **Intro** (простий текст під H1, посилання тут не працюють), **Body** (markdown: `## H2`, `- список`, `[текст](/ua/шлях)`; посилання пишемо з префіксом мови), **FAQ** (питання / відповідь).
H1 через CMS не міняється: для категорій він береться з `src/data/catalog/categories.ts`, для серій — з коду маршрутизації («Накладки Dignics», «Накладки Tenergy»).

Токени (`src/lib/content/tokens.ts`) підставляють живі значення під час рендеру:
- `{{models}}` — число разом зі словом, яке з ним узгоджується («43 моделі», «156 моделей», «10 моделей»). Використовую його замість фіксованих чисел.
- `{{price_from}}` / `{{price_from:dignics}}` — мінімальна ціна. **У нових текстах цін немає.** Якщо в поточному Body або FAQ ціна («від 1 035 грн», «від 3 950 грн») набрана руками, а не токеном, її варто замінити на `від {{price_from}}`: інакше після зміни ціни в адмінці текст показуватиме стару цифру.

Що бралося з живого сайту (10.11.2026): /ua/delivery — Нова Пошта або Укрпошта, самовивіз у Харкові, товари в наявності відправляють за 1–2 робочі дні, безкоштовна доставка від встановленої суми. /ua/payment — накладений платіж, при самовивозі готівка або картка, для юросіб — безготівковий розрахунок; **онлайн-оплати карткою зараз немає**. /ua/about — лише оригінальна продукція Butterfly з гарантією виробника. /ua/rakety — для збірної ракетки безкоштовні доставка, збирання й обрізання, торцева стрічка в подарунок.
Кирилиця (з Запросы.csv): «футболка батерфляй» — 11 показів, позиція 5,9; «накладки батерфляй» — позиція 6; «накладки баттерфляй» — 6 показів; «клей баттерфляй» — 3. Звідси UA «Батерфляй», RU «Баттерфляй». На кожну сторінку й мову припадає одна згадка, а в усіх інших місцях стоїть Butterfly. Для серій кирилицею написано назву серії, бо люди шукають саме модель: «тенерджи 19», «тенерджи 05», «дигникс 09с» (з пункту 1 вашого плану).
